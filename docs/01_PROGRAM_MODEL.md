# 01 – Program Model

## Tracks
| | **A – Merit Internship** | **B – Paid Training + Internship** | **C – Self-paced** (later) |
|---|---|---|---|
| For | Strong candidates, priority **AI Automation, AI/ML, BDA** | Students needing college internship / certificate / project | High volume, low touch |
| Student pays | No | Programme fee (+GST) | Low fee |
| Stipend | Minimal stipend or unpaid (decided per offer) | No | No |
| Content | Role playbook, real/supervised Quellflow work | Video course + playbook-style capstone in sandbox | Video course + assignments |
| Durations | 45 days · 90 days · 6 months (playbook) | 45 days · 90 days | Self-paced (access window) |
| Mentor time | 3–4 h / intern / week (playbook) | Weekly live session per batch + async review | Monthly Q&A |
| Updates | Daily update (written), weekly report | Daily update (short), weekly report | Weekly |
| Live | Mon goal · Tue teach · Wed review · Fri demo (playbook rhythm) | 1 scheduled live/week + host can add sessions anytime | Monthly |
| Selection | Form → Day 1–2 diagnostic / task → interview | Form → counselling call → payment → enrol | Direct |
| Documents | Offer letter, agreement, certificate, **experience letter**, relieving letter, LOR (earned) | Enrollment letter, invoice, completion certificate, project certificate, LOR (top performers only) | Course certificate |

Durations follow the playbooks: 45 days ≈ 6.5 weeks, 90 days ≈ 13 weeks, 6 months ≈ 26 weeks. Baseline 5 working days × 4 hours.

## Lifecycle (both tracks)
`applicant → shortlisted → (A: diagnostic / interview | B: counselling) → offer/enrolment → active → midpoint review → final demo → completion record → documents issued → alumni`

## Diagnostic & routing (from playbooks)
- Day 1 + Day 2 practical tasks per role.
- 5 dimensions scored 0–4: **Fundamentals, Execution, Problem solving, Communication, Verification** → total /20.
- Route: **0–7 Foundations**, **8–14 Guided**, **15–20 Accelerated**. Recheck on Day 7.
- Scores guide teaching; they are **not** an automatic hiring or rejection decision.
- Rescore the same 5 dimensions at midpoint and final using project evidence.

## Completion & grading
- Track A: completion = acceptance checks of the agreed (or rescoped) project brief met + mentor decision `accepted` + final demo done.
- Track B: weighted score – quizzes 15%, assignments 30%, capstone 40%, daily updates & attendance 15%; attendance ≥ 75%.
- Grade bands (certificate): **Distinction ≥ 85**, **Merit ≥ 70**, **Completion ≥ 50**. Below 50 → no certificate (participation letter optional – decision).
- "Do not label unfinished work as delivered" (playbook) – certificate text lists the actual project and scope.

## Non-negotiable rules
1. Track B is marketed as **Training + Internship Programme**; fee and what it covers are shown before payment.
2. Experience letters only for Track A interns who did real supervised Quellflow work.
3. Assessment tasks are never unpaid client delivery (playbook).
4. Interns use training workspaces/sample data; production/client access needs mentor approval.
5. AI tool use allowed but must be disclosed; interns explain their work (playbook "checking ownership").
6. GST on fees, invoices from the LLP, stipend TDS, refund policy → confirm with CA before launch.
