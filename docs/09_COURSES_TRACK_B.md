# 09 – Courses (Track B – Paid Training + Internship)

## Principles
- Reuse the playbook backbone (modules → project brief → acceptance checks → final demo/report) so Track B quality matches Track A; add **video lessons, quizzes and graded assignments** for scale.
- Durations aligned with playbooks: **45 days** (≈ 6.5 weeks) and **90 days** (≈ 13 weeks). 6 months stays Track A only.
- Capstone runs in sandbox/sample data, never on client work.

## Course structure (45 days)
| Week | Lessons (video + notes) | Practice | Graded |
|---|---|---|---|
| 1 | Onboarding, tools, playbook module 1 | Day 1–2 diagnostic (self-run, mentor-scored in live) | Quiz 1 |
| 2 | Modules 2–3 | Guided exercises | Assignment 1 |
| 3 | Module 4 | Exercise | Quiz 2 + Assignment 2 |
| 4 | Module 5 + project brief (45-day brief, simplified) | Capstone start | Capstone checkpoint 1 |
| 5–6 | Capstone build + failure/quality checks | Weekly review in live | Checkpoint 2 |
| 6.5 | Final demo (35-min agenda, condensed to 15 min) + final report | – | Capstone final |

90-day version: same modules with deeper practice + 90-day project brief + midpoint review (week 7) + supervised pilot week.

## Grading
Quizzes 15% · Assignments 30% · Capstone 40% · Daily updates & live attendance 15%.
Certificate: Distinction ≥ 85 · Merit ≥ 70 · Completion ≥ 50 and attendance ≥ 75%.
Top 5% by grade + mentor nomination → Certificate of Excellence and LOR eligibility; strong trainees can be invited to Track A.

## Weekly rhythm
- Mon: week unlocks (lessons + assignment brief).
- Daily: 5-min daily update (playbook template, short form).
- Weekly live (fixed slot, 60 min): demo + doubts + review of 2–3 submissions; recording posted.
- Host can schedule extra sessions anytime (portal → Schedule).
- Sun 11:59 pm IST: assignment due.

## Example – AA, AI Automation & Agents (45 days)
| Week | Topic |
|---|---|
| 1 | Workflow logic: triggers, conditions, outputs · n8n setup · JSON & HTTP basics |
| 2 | APIs & data formats: webhooks, mapping, validation · Google Sheets/Gmail nodes |
| 3 | Errors & repeated events: retries, event keys, dedupe · AI output checks: structured output, evaluation cases |
| 4 | Credentials & handover · Capstone brief: **Enquiry intake and routing workflow** (10-case test set) |
| 5–6 | Build: intake → validate → dedupe → AI categorise → manual review fallback → status log |
| 6.5 | Demo: normal, duplicate, invalid AI output cases + handover package |

## Content production checklist (per track)
- [ ] Syllabus approved (from playbook modules)
- [ ] 15–25 lessons recorded (8–15 min each) – screen + face optional; uploaded unlisted (YouTube) or Bunny Stream
- [ ] Notes / resource links per lesson (official docs, per playbook)
- [ ] 3–4 quizzes (10 MCQ each)
- [ ] 2–4 assignments with rubric
- [ ] Capstone brief + acceptance checks + sample data
- [ ] Mentor answer cues (mentor-only)
- [ ] Live session agenda per week
